The old combined Featured Creations Manager is now three focused, repository-aware tools.

Homepage
Featured Creations

The 4 hand-picked tiles shown prominently on the homepage.

  • Enabled state, title, price, alt, URL
  • Local upload or remote image
  • Live preview
Homepage + Explore page
Explore All

The Explore All grid — manual tiles or the Etsy Worker API with a manual fallback.

  • Manual / API + Fallback source modes
  • API URL, homepage-visible count, View All URL
  • Slot management & ordering
Heritage page
Heritage Gallery

The 10-slot slideshow on the Heritage page.

  • Image + alt text per slide
  • Enabled / disabled
  • Existing slideshow behaviour unchanged
Separate area
Originals Admin →

Project / journal entries and the Originals listings live in their own admin area.

How it works

  • All three tools read and write the single file /data/featured-creations.json.
  • Each tool only ever rewrites its own section — the other two are preserved untouched.
  • Connect the repository folder once (any tool) and every tool shares that connection: it loads the current data automatically and writes changes straight back.
  • No repo connection? The tool still loads the live data from the served site and exports a repository-ready ZIP.
  • Image directories are unchanged: assets/images/featured-creations/, assets/images/explore-all/, assets/images/heritage/gallery/.
