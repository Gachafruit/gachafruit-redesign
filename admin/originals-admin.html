Originals Admin

Two focused tools now handle what the old single Originals Manager did.

Publishing
Originals Project Manager

Create, edit, publish and archive project / journal entries.

  • One permanent file & image folder per project
  • Current vs. archived is a state change, not a file move
  • Publish straight to the repo folder, or export a ZIP
Listings
Originals Listings Manager

Manage the marketplace-facing parts of the Originals page.

  • Etsy section display settings
  • Free Models tiles
  • Writes /data/originals-content.json

Data map

  • /data/originals/projects-index.json — manifest: which project is current + every entry
  • /data/originals/projects/<id>.json — one file per project entry
  • /assets/images/originals/projects/<id>/ — that project's permanent image folder
  • /data/originals-content.json — Etsy settings + Free Models only
